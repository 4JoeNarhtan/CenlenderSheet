# 🗓️ To-Do List Calendar Sheet

This is a simple and interactive To-Do List combined with a Calendar interface. 
It helps users organize tasks based on dates and keep track of what needs to be done.

## ✅ Features

- Add, edit, and delete tasks
- View tasks based on calendar days
- Clean and user-friendly design UI
- Responsive layout for desktop and mobile
- Data stored temporarily (no backend yet)


## 🛠️ Built With

- HTML
- CSS
- JavaScript

## 🧠 Why I Built This

I built this project to improve my JavaScript skills and learn how to manage dynamic data on the front-end. 
It also helps me practice how real-world task managers work.
